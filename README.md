# 🛰️ KangCCTV

**CCTV Live Bekasi** — web sederhana buat lihat streaming CCTV yang ada di beberapa titik **Kota Bekasi**.

Project ini masih super simple dan baru berisi **1 file HTML**.  
Fokus utama saat ini hanya untuk CCTV Bekasi, karena tidak memungkinkan untuk langsung mencakup CCTV live seluruh daerah di Indonesia.

---

## 📌 Tentang Project

KangCCTV adalah project iseng tapi berguna buat:
- Monitoring kondisi lalu lintas
- Lihat situasi jalan secara realtime
- Belajar basic implementasi live stream CCTV via web

Belum ada backend, belum ada database, masih full static HTML.

---

## 🚀 Cara Pakai

1. Clone repository:
   ```bash
   git clone https://github.com/cpamungkas/kangcctv.git
   ```

2. Masuk ke folder project:
   ```bash
   cd kangcctv
   ```

3. Buka file `cctv.html` langsung di browser  
   atau pakai Live Server (VS Code) biar lebih enak.
